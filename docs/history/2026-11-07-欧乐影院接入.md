# 欧乐影院（olevod）接入 —— Vue SPA + Go WASM，接口自带 `_vv` 签名

> 2026-11-07。目标：把 `https://www.olevod.com/` 的内容接进 AIIvideo。
> 交付：`docs/samples/spiders/olevod.json` + `work/android/app/src/test/resources/spiders/olevod.js`。
> 已部署到 relay（`/srv/cfg/spiders/olevod.{js,json}`）并加进 `market-spider.json`。

## 一、站点形态判断

首页 HTML 是个空壳（只有 `<title>欧乐影院`），正文由 Vue 渲染：

```html
<script type="module" src="/js/tv-pc-index.<ts>.js"></script>
<script>
  const gos = new Go();
  WebAssembly.instantiateStreaming(fetch("/js/play.wasm"), gos.importObject)...
</script>
```

`play.wasm` 是播放页用的 wasm（2MB），跟取列表/详情无关。数据全在打包进
`tv-pc-main.<ts>.js` 里的一个 axios 实例上：

```js
Fe = C.create({ baseURL: "https://api.olelive.com" })
```

所以这不是盾后站、不用过 WASM —— 直接打 `api.olelive.com` 的 JSON 接口即可。判断
依据还是那条老规矩：能不能用 `curl` 拿到数据。能。

## 二、`_vv` 签名（唯一拦路的东西）

不带 `_vv` 直接请求任何 GET，服务器回 `401 用户签名错误`。签名在前端请求拦截器里
（`tv-pc-main.js` 的 `Fe.interceptors.request.use`）：

```js
if ("get" === e.method) {
  let t = fe(Date.parse(new Date) / 1e3);
  e.params = { ...e.params, _vv: t }
}
```

`fe()`（同文件）不是普通哈希，是「时间戳按位拆成 4 列 + md5 交织」：

```
t = String(unix秒)                      // 实测必须整数秒，带小数会被拒
每位的 charCode 转二进制 b（'0'..'9' → 6 bit）
r[0] += b[2] ; r[1] += b[3] ; r[2] += b[4] ; r[3] += b[5..]
a[i] = parseInt(r[i],2).toString(16) 补零到 3 位
n    = md5(t)                            // 32 位 hex
_vv  = n[0:3]+a0+n[6:11]+a1+n[14:19]+a2+n[22:27]+a3+n[30:]
```

`olevod.js` 里用一份公有领域 md5（Joseph Myers）纯 JS 复刻了它，沙箱没有 crypto 库、
没有 DOM，只能这样。已与 Python 独立实现对过：`fe(1794058765)=be2088e3a6c157e882a106648f539554`。

> 登录态还会往 params 里塞 `_he/_pl/_si`（token 拆三段），匿名访问用不到，源里不实现。

## 三、接口清单（全 GET，路径参数）

| 用途 | 路径 | 备注 |
|---|---|---|
| 轮播 | `/v1/pub/index/banners` | `bannerType=4` 是影片，id 就是 vod id |
| 最新 | `/v1/pub/vod/newest/{page}/{size}` | `{list,total,page,pageSize}` |
| 分类列表 | `/v1/pub/vod/list/{a}/{b}/{area}/{year}/{typeId1}/{typeId}/{letter}/{order}/{page}/{size}` | 见下方参数说明 |
| 搜索 | `/v1/pub/index/search/{kw}/{page}/0/0/0` | 返回 `data.data[]` 按 type 分组，取 `type==='vod'` |
| 详情 | `/v1/pub/vod/detail/{id}/{解析开关}` | 见下方 |
| 分类树 | `/v1/pub/vod/list/type` | 顶层 + children，用来生成 ui 配置 |

分类列表 10 个位置参数的实义（从 `tv-pc-Nav` chunk 的 `pubVodList(...)` 调用点反推）：

1. 恒 `1`（是否分页）
2. VIP 过滤：3=全部 / 1=会员 / 2=免费
3. area（地区，如 `美国`，URL 编码）
4. year（年份）
5. typeId1（顶层分类：1 电影 / 2 连续剧 / 3 综艺 / 4 动漫 / 5 午夜 / 6 蓝光 / 14 短剧）
6. typeId（子分类，如 101 动作片；填了它第 5 位传 0 也行）
7. letter（首字母）
8. order：`update` / `desc` / `hot` / `score`
9. page
10. size

**size 只认 12 / 36 / 48**（传 24、60 会被服务器回落到 12）。源里用 36。

### 详情页的第二个参数是开关

`/v1/pub/vod/detail/{id}/0` → `urls[]` 里每集 `url` 全是空串（只要选集目录）；
`/1` → 每集 `url` 填好真实 m3u8。所以一个 `/1` 请求就能同时拿元数据 + 全部直链。
播放阶段再按集号取一次（直链不缓存，避免过几小时过期）。

## 四、播放

`urls[].url` 是普通 HLS：master 里是相对路径 `index-v1-a1.m3u8`，分片 `seg-N-v1-a1.ts`
也同域相对，没有 `EXT-X-KEY`。抽了 **432 部 / 7360 条 url**，只出现两个 CDN：

```
cloud.yuntongclouds.com   （主）
dubo.oulehdtv.tv          （少量）
```

两个都写进 `http.hosts`（精确匹配）。真机若报「主机不在播放层白名单：xxx」就把新名补进去。

## 五、降级

午夜影院(5)、VIP 蓝光(6) 是会员专区：匿名 `detail` 返回 `vip=true` 且 `url` 为空。
`play` 不塞空地址，返回 `reason:'vip'`（界面按原因提示），这是规范允许的正常降级。

## 六、封面

`image_base=https://static.olelive.com`，接口里 `pic` 是相对路径 `upload/vod/...`，
补成 `https://static.olelive.com/upload/...`。明文直出，`cover.mode=plain`。

## 八、踩点记录

- `fe(Date.parse(new Date)/1e3)` 字面是浮点秒，但实测**浮点会被 401**，整数秒才过 →
  源里 `Math.floor(Date.now()/1000)`。

## 九、2026-11-08 真机「无法播放」排障与更正（重要）

首版交付后真机打开首页直接「加载失败：banners/newest/list 全空」。logcat（`adb logcat -s HG.Spider`，
真跑在 `com.huangguo.mobile:spider` 进程）里每个请求都是：

```
op=net okhttp 失败：HTTP 403 @ https://api.olelive.com/v1/pub/index/banners?_vv=...
net api.olelive.com → 直连（直连表命中） profile=有 mode=builtin proxy=有
```

### 根因：geo 403 + 我配错了 net

- 欧乐是「面向海外华人」的站，`api.olelive.com` / 播放 CDN / 封面图床对**大陆出口一律 HTTP 403**
  （空 body）。实测对照：Mac 出口在洛杉矶（US）→ 200；手机直连（大陆 5G）→ 403；
  手机走 `Clash Meta` 的美国节点 → 200。
- 第一版配置里写了 `"net": {"declared": true, "proxy": []}`，按规范这是「全直连」。
  `NetRoute.directOnly()` 里 `declared && proxy空` → `!matches(空,h)=true` → 直连 ⇒ 全站 403。
  **这是这次的真凶**：不是源解析错，是把本该走代理的站强制成了直连。

### 修复

```json
"net": { "declared": true,
         "proxy": ["api.olelive.com","static.olelive.com",
                   "cloud.yuntongclouds.com","dubo.oulehdtv.tv"] }
```

改了 `docs/samples/spiders/olevod.json` 并 scp 到 `/srv/cfg/spiders/olevod.json`，用户重装源后：
- `net api.olelive.com → 代理`，首页正常出轮播+卡片；
- 点播：`[relay] 上游 200 经代理 …master.m3u8`、variant 331 段、`seg-1..seg-8 200 经代理`，
  `c2.qti.avc.decoder` 渲染帧数递增、Drop 0 → **能播**（截屏黑是因为硬件视频层截不到，不是没画面）。

### 顺手修的封面灰块

部分封面灰块，logcat 是 `图片无法解码 … static.olelive.com`。原因：详情 `pic` 大图常是
**WebP**（个别变体 App 的 BitmapFactory 解不了），而接口另给的 `picThumb`（`…_384x560.jpg`）
是标准 JPEG。已把 `olevod.js` 的卡片/详情封面改成 `picThumb || pic`，JPEG 必能解。

### 结论（给以后接欧乐的人）

- 这个源**必须走代理**（至少 `net.proxy` 这四个域），App 侧内置核心/Clash 要是通的；
  关掉代理就回到 403，不是源坏了。
- 判断「403 vs 401」很关键：401=签名错（`_vv` 算法/时钟），403=出口/IP 被 CDN 拒（geo/代理没生效）。
