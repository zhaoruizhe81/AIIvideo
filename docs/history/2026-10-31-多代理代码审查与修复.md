## 修复清单（按模块，行号为修复时位置）

**桥接/主界面**
- MainActivity 11 处异步回点（更新进度/云同步/头像/预测性返回等）补 `isDestroyed() || webView == null` 守卫——`onRenderProcessGone` 置空 webView 后，分钟级下载的进度回调会在 UI 线程 NPE（本批唯一 P0）。
- `download-update` 防重入：`isDownloading()` 时抛「已有更新在下载中」（前端据此把界面拨回下载态而不是误报失败）。
- HuangGuoApp 预热、localStorage 迁移两处静默 catch 补日志；迁移的 `originMigrated` 落盘挪出易抛段。删 `isLocalCommand` 死条目 age-status。

**播放器**
- AndroidManifest 给 VlcPlayerActivity 加 `singleTask`：原 standard 模式下 `onNewIntent` 整段不可达，快速双击播放会叠实例（旧实例整套 LibVLC 不释放、进度互相覆盖）。同时修该段三坑：feed 进度落盘调错函数、payload merge 残留旧键、跨 feed↔单集形态不重建 UI。
- VlcControlsView 收提示改单一 Handler 字段（跨实例 removeCallbacks 永远删不掉对方消息）。
- persist/persistFeedProgress/attachVout 静默 catch 补日志；MediaProxy 空 reasonPhrase 补 default；中继读超时 0→120s。

**网络出站**
- AiiHttp.clientFor 直连分支不再每次请求裸 new OkHttpClient（默认 direct 模式连接复用全失效的根因）；换路用 `newBuilder().proxy(null)` 派生。
- Outbound.hostOf 收成唯一实现（HttpUrl 宽松优先、URI 兜底），AiiHttp 与 VlcRelay 两通道代理判定口径统一；VlcRelay.resolveAbs 与 rewriteTagUris 同款宽松回退，失败不包 `u=`（原样会在 serve 抛异常→解密黑屏）。
- AiiHttpCache warmup settle 后消费式摘除（60 秒内 /api/home 每次回启动快照）；RouteMemory learn/forget 的 entries() 挪进锁内；VlcRelay accept 补日志+防忙转；serve 持有上游 Call、客户端断开即 cancel。

**代理/订阅**
- ProxyConsole.proxyStart 删掉解析前的提前落盘——原来粘错一条坏链接就永久覆盖存档好链接（与函数自己的注释矛盾）。
- parseUrlStyle 缺端口回落 443 真正生效；Subscription 名单补 socks://、Clash 缺字段改记账不静默、looksLikeClash 改行首匹配+空结果回退；pickPort 成对探测 +1 端口；SocksBridge 退出复位端口防死端口；NodesFeed.refresh 串行化；GeoIp 补日志并去掉桥线程同步 DNS；ProxyRoute 对 `https://` 外部代理显式拒绝；nodeFromJson/去重指纹补 sni/publicKey 等字段；迁移空 catch 补日志。

**Spider 运行时**
- **Binder 超限**：装源门禁 2MB 但每次调用把全量源码塞进一条同步 AIDL（Binder 缓冲约 1MB），600KB～2MB 的源装得上永远调不通。改为传「路径+大小+mtime 指纹」、:spider 进程自读（路径限定源目录内、指纹不符拒执行）；盾回填页 512KB/700KB 双闸、回程 >700KB 明确报错。规范契约（ABI=1、js ≤ 2MB）未动。
- ensureImageView 复用判定绑错 alive：纯封面场景每次取图都销毁重建整个 WebView 单例，并发时拆掉在飞请求。
- doFetchByNav 加「文档真的变空白」确认 + URL 同源校验 + 计数复位，不再把 warmup 旧页当抓取结果（空白 5s 确认不到改为明确失败，真机回归留意 `[site-wv]` 日志频率，必要时调大 BLANK_WAIT_MS）。
- bind 被拒绝复位可重试；netAll 单独识别 ShieldSignal 走主进程过盾回填、gate 中断不再无证放行；6 处静默 catch 补日志；安装 tmp 加随机后缀；数字 requires 按 ABI 门禁拒装；宿主页 cookie 源间清理；bin 通道 8MB 闸；注入前校验宿主页 URL。

## 延后项当晚全部落地（2026-10-31 深夜）

1. **CSP**：app.html 加 meta（`default-src 'none'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src * data:; connect-src 'none'; media-src 'none'; object/base/form/frame 全 none`）。策略逐条有 grep 证据背书（全项目 fetch/XHR/WS 零使用）；一处必要偏离：hxm 的 `WebAssembly.instantiate` 是 AGE 解析活路径，Chrome 58 WebView 只认 `'unsafe-eval'` 不认 `'wasm-unsafe-eval'`，底线到 96+ 后可收窄。另加 `securitypolicyviolation` 上报钩子（缓冲 20 条 + 3/8/15s 兜底补发，走 track）供真机回归。
2. **VlcRelay HMAC**：进程内 SecureRandom 密钥；4 个中继 URL 构造点（wrap、rewriteM3u8、rewriteM3u8Smart、rewriteTagUris）统一走 `relayUrl()` 带 `&k=<HMAC-SHA256(u)>`；serve 在 decode 后先验签，缺失/篡改/换 u 一律 403（常量时间比较）。无签名地址永不外发（签名失败 wrap 退直连并留日志）。
3. **DNS rebinding**：`AiiHttp.getRawPinned(url, extraHeaders, pinnedAddrs)`（2 参便捷版委托）——`newBuilder()` 派生 DNS 只答钉死地址组、只直连、不换路、不学路由；SiteRepository.probeBare 改为解析一次 → `rejectPrivateAddrs`（原逐地址判定逻辑不变）→ 钉死直连，Referer 经 extraHeaders 保留，无回退。grep 确认全仓库 check-then-use 配对仅此一处。
