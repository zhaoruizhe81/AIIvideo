# 文档索引

这份索引管两件事：**哪些是现在的口径**，**哪些只是历史**。看文档先看这张表，
别一上来就翻 `history/` 里某篇三周前的日报然后照着做。

判定规则只有一条，2026-10-21 起执行：

- 文件名带日期 = 当时的现场记录，进 `docs/history/`。
- 文件名不带日期 = 仍然要照着做的口径，留在 `docs/` 根目录。

## 四、写新文档的规矩

1. **当天的事写当天**：文件名用 `YYYY-MM-DD-主题.md`，直接写进 `history/`。
2. **沉淀成规矩的那部分**不留在日报里 —— 契约进《spider-接入规范》，字段进《站点配置参考》，
   发版流程进《开发说明》。日报只留现场：数字、日志、踩到的那一刻。
3. **不在历史文档上原地改结论**。后来的更正另写一篇，两篇互相指，别把旧的改得像新的。
4. **数字要现算**。这个仓库的文档历史上漂过：单测写过 184/201/275/317/335，实际 236；
   APK 写 47MB，实际 42.9MB。写之前跑一遍命令。
