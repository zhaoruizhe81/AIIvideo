# 模块划分（9 模块维护口径）

代码按 **9 个模块**维护。改任何文件之前先在这张表里找到它属于哪个模块、有什么坑，
改动直接落到对应模块，**不做跨模块顺手修改**（跨模块约定见文末速查，破坏约定先在
PR/说明里写清楚）。本表源自 2026-10-31 的九代理全量审查分工（现场记录见
[history](history/2026-10-31-多代理代码审查与修复.md)），此后作为维护口径持续更新。

路径约定：Java 全在 `work/android/app/src/main/java/com/huangguo/mobile/`，
前端全在 `work/android/app/src/main/assets/`（`site-web.js` 是构建产物，改
`site-default.json` + `gen-web-config.py`）。

## 各模块职责与改动注意

### 1. 桥接与主界面
WebView 装载、`Bridge.registerCommands()` 约 40 条指令、`dispatch()` 门禁前指令、生命周期、主题、返回手势。
- 新桥指令 = `registerCommands()` 一行 + 前端 `api()`，不要进 `dispatch()`；`content-status` 是唯一留在 dispatch 的门禁前指令（历史原因，见类注释）。
- **每个异步回点必须带 `isDestroyed() || webView == null` 守卫**——渲染进程死亡会把 webView 置 null，分钟级回调（下载/同步）最容易踩。
- 文件里有 jadx 反编译残留（`dark()`、`requestDone` 三层 catch 是同一 handler 的展开），动前读懂再改。

### 2. 播放器（libVLC）
播放界面、feed 双 player（A/B 预热）、控制层、本地 WebResource 中继（MediaProxy）。
- VlcPlayerActivity 是 `singleTask`：再次拉起走 `onNewIntent`——payload **整体替换**（不许 merge 残留旧键）、按新 payload 重算 `feedMode/eps/curPos`、跨 feed↔单集形态要重建 UI。
- 进度落盘按模式分派：feed 走 `persistFeedProgress()`、单集走 `persist()`，别调错。
- 控制层收提示只用 `hintHandler` 字段（新起 Handler 的 removeCallbacks 删不掉别人的消息）。

### 3. 网络出站
唯一的出站实现 `Outbound`（请求头模板 + 代理判定），`AiiHttp`（接口/封面/spider net）与 `VlcRelay`（播放取流）两条通道共用。
- 换路派生 client 只用 `newBuilder()`（共享连接池/拦截器），**禁止裸 new OkHttpClient**。
- host/代理判定只走 `Outbound.hostOf/viaProxy`（HttpUrl 宽松优先），别再写 `new URI(url)`。
- **VlcRelay 的中继 URL 一律走 `relayUrl()` 签名**（HMAC `&k=`），serve 验签 403——新增构造点不签名 = VLC 黑屏；现有四个构造点：wrap、rewriteM3u8、rewriteM3u8Smart、rewriteTagUris。
- `getRawPinned` 只直连、不换路、不学路由，专供私网校验后的钉死 IP 请求，别改回会二次解析的路径。
- 所有后端地址只在 `Endpoints.java`。

### 4. 代理与订阅
内置 xray（进程内 libv2ray so，无子进程）配置生成、订阅解析、节点池、本地 SOCKS、测速、国家表。
- 分享链接的 scheme 名单**三处同步**：`parseShareLink` / `looksLikeLink` / `containsScheme`（hy2、socks:// 都栽过）。
- 配置 JSON 一律经 org.json `put`（自动转义），禁止手拼字符串。
- 去重指纹 `signatureOf` 与 `ProxyCore.sameNode` 字段口径保持一致；缺字段的节点必须 `failed++` 记账，不许静默消失。
- `pickPort` 成对探测 port 与 port+1（HTTP 入站 = SOCKS+1）。

### 5. Spider 运行时
spider 源装载/门禁/沙箱执行（`:spider` 进程）、主进程抓取 WebView（过盾、封面）、Binder 通道。
- **Binder 只传「路径 + 大小 + mtime 指纹」**，`:spider` 侧 `readInstalledSource` 自读自校验——别把源码塞回请求（>1MB 必炸 TransactionTooLarge）；盾回填页单页 512KB/总量 700KB 闸、回程 >700KB 明确报错。
- `doFetchByNav` 的「空白确认 + URL 同源校验 + 计数复位」是一套，别拆（拆了会把 warmup 旧页当结果）。
- ABI 门禁原则「认不出来一律拒绝」；js ≤ 2MB 契约见 [spider-接入规范](spider-接入规范.md)。
- `hxm/` 是 AGE 播放解析的前端层（wasm，CSP `'unsafe-eval'` 就是给它开的），改动连带核对 app.html 的 CSP meta。

### 6. 存储与账号
prefs 键空间（`user:<objectId>:` 前缀 + 墓碑）、账号云同步、源配置（内置/用户/市场三层）、埋点队列、封面信任。
- 键空间切换（登录/登出）时裸键墓碑**按时间 max 并入**用户键空间后再删，否则云同步复活已删条目。
- `ReportQueue` 的 rename 前必须查目标 `.jsonl` 是否已存在（发送窗口内新事件会重建同名文件），存在则合并写回。
- `factoryReset` 必须含 `files/source-cache/` 与 `files/spiders/`。
- 裸拉直连的私网校验 = 解析一次 → `rejectPrivateAddrs` → `getRawPinned`（DNS rebinding 防护），别改回两次解析。

### 7. 更新
APK 自更新（清单五道闸校验、镜像下载、sha256、装包）。前端热更通道**已停用**（2026-10-19，三条桥指令是 stub，`hot/` 是遗留现场）。
- `cached()` 零网络（回放缓存），镜像 `pick()` 只在 `download()` 时做一次。
- `isDownloading()` 是 volatile 读，别加 synchronized（download 全程握锁，同步读 = 预检失效）；「已有更新在下载中」这个异常文案是模块 1↔7 的契约，前端靠它回拨状态。
- sha256 比较用 `MessageDigest.isEqual`；清单字段五道闸缺一不可。

### 8. 前端核心
路由/导航/渲染管线、Bridge 回调管理层、数据适配（model/adapters）、错误上报、卡片过渡。
- `bridgeCall(action, args, timeoutMs)` / `api(...)` 第三参：缺省 45s、**传 0 不限时**——spider 类调用两端都传 90000，分钟级操作传 0。
- 所有 `await` 之后重画页面前必须校验 `routeToken` / `state.route`（桥回包晚到的经典串台）。
- 外部字符串进 innerHTML 必过 `esc()`——`HG_SITE.ui` 整块（源提供的远程配置）当前五处已过，新增渲染点沿用。
- 页面 CSP meta 在 app.html（模块 9），`connect-src 'none'`：**前端联网只许走桥**，新增 fetch/XHR = 破坏安全模型。

### 9. 前端功能页
播放拉起层（feed-player 的 open/close 走原生）、代理面板、首启设置、源市场、封面加载、搜索/列表/详情页。
- feed-player 里 `<video>` 状态机是**死代码**（render 及以下不可达，播放全走原生），别误当活路径改。
- 滚动容器是 `#scroll`，不是 `document.scrollingElement`（html,body overflow:hidden）。
- cover 失败分档：兜底直连失败冻 30s、`data:` 字节解不开才冻 300s；缓存 key = host + pathname。
- 市场安装走 `marketInstalling` 互斥；app.html 里的静态按钮监听用 `onclick` 覆盖式（addEventListener 会摞）。

## 跨模块约定速查

1. 前端↔原生只有 `AndroidHost.request(回调id, 指令名, json)` 一条路；判定路由全通 = logcat「未知请求」0 次。
2. 出站请求只有 `Outbound` 一份实现；地址只在 `Endpoints`。
3. 页面 CSP `connect-src 'none'`：前端联网只走桥（hxm wasm 走 `'unsafe-eval'`，与网络无关）。
4. 静默子系统必须打日志：`Log.d("AIIvideo", "[模块前缀] ...")`，空 catch = bug。
5. 测试与模块对应：`app/src/test` 的类名前缀即模块（AiiHttp*/Vlc*/Proxy*/Spider*/Subscription*/Cover*/Report*/UpdateMirror/Xray*/Outbound/NetRoute/RouteMemory...），改哪个模块就连带跑它的测试，跑法见 [work/android/README.md](../work/android/README.md)。
